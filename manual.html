2

Como publicar uma nova Prestação de Contas

Este é o principal uso do painel. Siga os passos:

  • Faça login no painel administrativo
  • Clique em "Prestação de Contas" no menu lateral
  • Clique no botão verde "Novo relatório"
  • Preencha: Mês, Ano, Receitas, Despesas e Atendimentos
  • No campo "Descrição do mês", escreva um breve resumo das atividades
  • Se tiver um PDF ou imagem do relatório oficial, clique em "Anexar" e selecione o arquivo
  • Em "Status", selecione "Publicado" para aparecer no site
  • Clique em "Salvar relatório"
✅ Após salvar, o relatório aparece automaticamente na página "Prestação de Contas" do site público, sem precisar fazer mais nada!
3

Como editar ou corrigir um relatório já publicado

  • Vá em Prestação de Contas no menu lateral
  • Encontre o mês que deseja corrigir na tabela
  • Clique no botão "Editar"
  • Faça as correções e clique em "Salvar relatório"
4

Como excluir um relatório

Na tabela de Prestação de Contas, clique no botão vermelho "Excluir" ao lado do relatório. O sistema pedirá confirmação antes de apagar.

⚠️ A exclusão é permanente e não pode ser desfeita. Tenha certeza antes de confirmar.
5

Dicas importantes

  • Os dados ficam salvos no navegador do computador (localStorage). Se trocar de computador ou limpar o histórico do navegador, os dados podem ser perdidos. Recomendamos fazer backup periodicamente.
  • Para ter os dados em qualquer computador, o ideal é hospedar o site em um servidor com banco de dados — converse com o técnico responsável.
  • Sempre que salvar um relatório, verifique no site público se ele apareceu corretamente.
  • O link "Ver site público" na barra lateral abre o site em uma nova aba para conferência.
  • Publique os relatórios até o dia 10 do mês seguinte.
6

Estrutura dos arquivos do site

  • index.html — Página principal (site público)
  • admin-login.html — Tela de login do painel
  • admin-painel.html — Painel administrativo completo
  • manual.html — Este manual
📁 Todos esses arquivos devem estar na mesma pasta no servidor de hospedagem.
